## 第 0 步 · 当前项目状态

代码已经全部写完，**默认运行在「本地存储模式」**，开箱即用：

| 项目 | 当前值 | 说明 |
| --- | --- | --- |
| `utils/config.js` 里的 `CLOUD_ENV` | 留空 | 留空 = 本地模式，作品存手机本地缓存 |
| 作品数据 | 本机缓存 | 界面与流程跟云端版完全一致 |
| 配方数据 | 前端写死 18 条 | 不依赖数据库 |
| 教程内容 | 前端写死 5 步 | 不依赖数据库 |
| `project.config.json` 里的 `appid` | `wxREPLACE_WITH_YOUR_APPID` | 占位值，导入项目时会被工具覆盖 |

**关键点**：填不填云环境 ID，只影响「作品存哪儿」，不影响你能不能跑起来。所以现在就可以直接部署。

## 第 1 步 · 安装微信开发者工具

1. 打开官方下载页：
   <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 选择 **稳定版 Stable Build** → **Windows**（64 位）→ 下载并安装。
3. 安装完成后打开工具，用**手机微信扫码登录**。

> 注意：扫码登录只是用你的微信号登录工具，**不等于注册小程序账号**，这一步不需要任何注册。

---

## 第 2 步 · 用测试号跑起来（不用注册，今天就能做）

### 2.1 导入项目

1. 打开开发者工具，点左侧「**小程序**」或顶部的「**+**」→ **导入项目**。
2. 填写：

   | 字段 | 填什么 |
   | --- | --- |
   | 项目名称 | 随便，例如 `qingchengcharan` |
   | 目录 | 点右侧文件夹图标，选择 `g:\projects\qingchengcharan` |
   | AppID | **点输入框右侧的「测试号」按钮**（见下方说明） |
   | 后端服务 | 选 **不使用云服务** |
   | 语言 | JavaScript |

3. 点「导入」。

### 2.2 关于「测试号」按钮

- AppID 输入框右边有一个小按钮写着「**测试号**」（部分版本叫「无 AppID」或「使用测试号」）。
- 点一下，工具会自动填入一个测试用 AppID，并覆盖 `project.config.json` 里的占位值。
- **这样就不需要任何注册**，直接能编译运行。

> 关于「后端服务」选项：它只决定**新建云开发模板项目**时是否自动生成云函数、云开发目录，**不影响已有项目能不能用云开发**。
> 测试号阶段看不到「云开发」入口，原因是**测试号不支持云开发**，跟这里选什么无关。换成正式 AppID 后入口就会出现，见 [5.1](#51-开通云开发)。

### 2.3 必做的一次设置：关闭域名校验

我们的占位图片和视频是**在线外链**，默认会被小程序拦截。必须关掉校验：

**工具右上角「详情」→「本地设置」→ 勾选：**

```
☑ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书
```

> 项目里 `project.config.json` 已经预设了 `"urlCheck": false`，但不同工具版本会以「详情」面板为准，**请务必进面板肉眼确认这个勾是打上的**，否则首页横幅和教程配图会显示不出来。

编译成功后（快捷键 `Ctrl + B`），逐条对照验收：

| # | 验收项 | 预期结果 |
| --- | --- | --- |
| 1 | 底部导航 | 出现 4 个 tab：首页 / 茶染教程 / 配方参考 / 我的作品 |
| 2 | 首页 | 品牌标题、横幅图、青城四色 4 个色块；点色块会展开颜色说明 |
| 3 | 首页三个按钮 | 分别跳到茶染教程、配方参考、我的作品 |
| 4 | 教程页 | 顶部完整流程视频 + 5 个步骤卡片，每步有配图和要点 |
| 5 | 配方页 | 原料 6 种 × 布料 3 种任意组合，点「查看推荐配方」都有不同结果 |
| 6 | 我的作品 | 顶部头像 + 昵称 + 作品数量；「关于我们」「联系传承人」可点 |

**测试号下不能测**：云开发（云数据库 / 云存储）、真机拍照上传、代码上传发布。这些留到第 5、6 步。

## 第 4 步 · 注册正式小程序账号

> 只有注册了正式账号，才能开通云开发、真机预览、发布上线。

### 4.1 ⚠️ 邮箱这一关（最容易卡住的地方）

注册用的邮箱必须**同时**满足三条硬性要求：

1. 没在**微信公众平台**注册过
2. 没在**微信开放平台**注册过
3. **没绑定过你的个人微信号**

**如果你现在这个邮箱已经被个人微信绑定，别犹豫，直接换一个新邮箱。** 这是最快的解法：

- 去 <https://mail.qq.com> 注册一个全新 QQ 邮箱（1 分钟），或网易 / Gmail 等任意新邮箱。
- 新邮箱**不要**绑定到个人微信上。

> 典型死循环长这样：用旧邮箱登录 → 提示「还没有注册公众号」；去注册 → 提示「该邮箱已被占用」。
> 原因是旧邮箱被微信生态里的**其他类型账号**（开放平台、或注册到一半被锁定的记录）占用了，而登录入口只认「公众号」这一类，所以两边对不上。**换邮箱 5 分钟解决，别在旧邮箱上耗。**

### 4.2 注册步骤

1. 打开 <https://mp.weixin.qq.com> → 右上角「**立即注册**」→ 选择「**小程序**」。
2. 填**新邮箱** → 收激活邮件 → 点邮件里的激活链接。
   - 激活页面会提示邮箱要求，确认满足 4.1 的三条即可通过。
3. 设置密码 → 主体类型选「**个人**」。
4. 按提示填身份证信息，并用**本人微信**扫码做身份验证（扫脸）。
5. 填写小程序名称（例如「青城拾色」）、简介、服务类目（可先随便选，后续能改）。
6. 完成后进入小程序后台。

> **费用**：个人主体小程序**注册免费**，也不需要 300 元认证费。只有涉及支付、特殊类目才需要认证。

### 4.3 拿到 AppID

小程序后台 → 左侧「**开发**」→「**开发管理**」→「**开发设置**」→ 顶部即是：

```
AppID(小程序ID): wx1a2b3c4d5e6f7g8h
```

复制它。回到开发者工具：

- 如果项目已经打开：点右上角「详情」→「基本信息」→ 点 AppID 旁的「修改」→ 粘贴新 AppID。
- 或者：重新「导入项目」，这次 AppID 填你自己复制的这个。

## 第 5 步 · 开通云开发并切换云端模式

### 5.1 开通云开发

> **看不到「云开发」按钮时，按下面顺序排查**（多数人卡在第 1 条）：
>
> | # | 检查什么 | 怎么查 | 不符合怎么办 |
> | --- | --- | --- | --- |
> | 1 | AppID 是不是测试号 | 右上角「详情」→「基本信息」，看 AppID 旁是否标着「测试号」 | 测试号**不支持云开发**，按钮不会出现。按第 4 步注册正式账号后换 AppID |
> | 2 | 账号是否完成主体信息与实名 | 小程序后台看是否有未完成的提示 | 未实名无法开通云开发，按后台提示补全 |
> | 3 | 工具版本是否过旧 | 「帮助」→「检查更新」 | 升级到最新稳定版后重新打开项目 |
> | 4 | 工具栏太窄按钮被折叠 | 拉宽工具窗口看右上角 | 「设置 → 工具栏管理」里把「云开发」勾上 |
>
> 换好正式 AppID 后，建议**关闭项目再重新打开**（不是只重新编译），工具栏才会刷新出「云开发」。
>
> 官方文档里「新建项目时后端服务选微信云开发」是针对**全新项目**的流程；我们是从已有目录导入的项目，直接用工具栏的「云开发」按钮即可，效果一样。

1. 用正式 AppID 打开项目后，点开发者工具**顶部工具栏的「云开发」按钮**。
2. 首次会弹出开通页 → 同意协议 → 选择**免费的基础版**套餐（个人研学场景额度足够）。
3. 开通后进入云开发控制台 → 创建一个环境：
   - 环境名称：例如 `qingcheng-prod`
   - 环境别名：随便
   - 点确定，创建完成后**复制环境 ID**（形如 `qingcheng-prod-1g2h3i4j5k6l`）

### 5.2 建数据库集合

云开发控制台 → 左侧「**数据库**」→「**+**」新建集合：

| 集合名 | 权限设置 | 说明 |
| --- | --- | --- |
| `works` | **仅创建者可读写** | 每个学员只能看到自己的作品 |

> 权限一定要选「**仅创建者可读写**」。选错了会导致所有人互相看到彼此的作品。
> 本期**不需要**创建 `recipes` 集合，配方数据写死在前端。

### 5.3 填环境 ID 并切换

打开 [utils/config.js](../utils/config.js)，把第 17 行的 `CLOUD_ENV` 改成你的环境 ID：

```js
const CLOUD_ENV = 'qingcheng-prod-1g2h3i4j5k6l'   // ← 换成你复制的环境 ID
```

保存后回到开发者工具，**重新编译**（`Ctrl + B`）。控制台出现下面这行即表示切换成功：

```
[青城拾色] 云开发模式已启用，环境： qingcheng-prod-1g2h3i4j5k6l
```

### 5.4 验证云端是否真的生效

1. 清一下本地缓存：工具顶部「清缓存」→「清除数据缓存」。
2. 「我的作品」页顶部应显示「**已存云端**」而不是「存在本机」。
3. 新增一件作品 → 打开云开发控制台 →「数据库 → works」应出现这条记录 →「存储」应出现这张图片。
4. 换另一个微信号（另一个账号）打开小程序，「我的作品」应该是空的 —— 说明「仅创建者可读写」权限生效。

## 第 6 步 · 真机预览与发布体验版

### 6.1 真机预览

1. 点工具顶部的「**预览**」→ 生成二维码。
2. 用手机微信扫码打开。
3. 在手机上验证：**拍照 / 从相册选图上传作品**、分享给好友。

> 至此前面的 7 步里，「拍照上传」这一步才第一次真正被验证到 —— 测试号做不到，所以必须等到有了正式 AppID。

### 6.2 发布体验版

1. 工具顶部点「**上传**」→ 填版本号（如 `1.0.0`）和项目备注 → 确定。
2. 打开小程序后台 →「版本管理」→「开发版本」→ 找到刚上传的版本 →「**选为体验版**」。
3. 后台「成员管理」→「体验成员」→ 添加需要试用的同事 / 学生。
4. 把体验版二维码发给他们即可。

> 正式上线还要提交审核（后台「版本管理」→「提交审核」），按提示填即可。

## 第 7 步 · 后期替换素材与文案

日常维护只需要动这几个文件，**页面代码一行都不用改**：

| 想改什么 | 改哪个文件 | 怎么改 |
| --- | --- | --- |
| 图片 / 视频 | [utils/assets.js](../utils/assets.js) | 文件里每处都写了「换成真实素材时改为 xxx」的注释，照着改 |
| 首页横幅视频 | [utils/assets.js](../utils/assets.js) | 填 `HOME_BANNER_VIDEO` 的远程地址；留空则显示横幅图 |
| 联系方式 | [utils/config.js](../utils/config.js) | 改 `CONTACT` 里的手机号、微信号、地址 |
| 关于我们文案 | [utils/config.js](../utils/config.js) | 改 `ABOUT.intro`、`ABOUT.version` |
| 配方数据 | [utils/recipeData.js](../utils/recipeData.js) | 直接改数组，18 条，页面自动更新 |
| 教程内容 | [utils/tutorialData.js](../utils/tutorialData.js) | 直接改 5 个步骤的文字和配图 |

**放素材**：把真实图片丢进 `images/` 目录，然后把 `utils/assets.js` 里的在线占位地址换成 `/images/xxx.jpg`。

> 小技巧：**本地 `images/` 里的图片不受域名校验限制**，比外链更稳定。如果真机上出现图片不显示，优先考虑改用本地图片。

### 视频必须放代码包外面

小程序**单个代码包上限 2MB**（全部包加起来 20MB）。视频文件放本地目录会被打进代码包，超过 2MB 会导致**真机预览和上传直接失败**。

- `videos/` 目录已在 [project.config.json](../project.config.json) 的 `packOptions.ignore` 里排除，**不会被打包**，可以当本地素材库用。
- 首页横幅视频填 [utils/assets.js](../utils/assets.js) 里的 `HOME_BANNER_VIDEO`，地址必须是**代码包外的远程地址**（云存储 / CDN）。
- 正式上线前，视频域名要加进小程序后台「开发设置 → **服务器域名 → downloadFile 合法域名**」。
- `HOME_BANNER_VIDEO` 留空时首页自动显示横幅图，不会报错。

## 常见问题排查

### 图片 / 视频都显示不出来
→ 99% 是没关域名校验。回到「详情 → 本地设置」，勾选「不校验合法域名…」，然后重新编译。

### 「该邮箱已被占用」/「还没有注册公众号」死循环
→ 见上面「第 4 步 → 4.1 邮箱这一关」。直接换一个全新邮箱，别折腾旧邮箱。

### 找不到「云开发」按钮
→ 先看 AppID 是不是**测试号**（「详情 → 基本信息」会标注）。测试号不支持云开发，入口不会出现，跟导入时「后端服务」选什么无关。换成正式 AppID 后**关闭项目重新打开**再看。详见上面 [5.1](#51-开通云开发) 的排查表。

### 云开发报错、提示未开通 / `-501000`
→ 三个前提缺一不可：① 用的是**正式 AppID**（不是测试号）② 已经在工具里**点过「云开发」并开通** ③ `utils/config.js` 里 `CLOUD_ENV` **填了正确环境 ID**。

### 作品能新增，但控制台里看不到数据
→ 检查集合名拼写是否严格为 `works`（全小写），以及 `utils/config.js` 里的 `COLLECTION_WORKS` 是否一致。

### 换了个微信号，看不到自己的旧作品
→ 正常现象。云开发的 `_openid` 是跟着微信号走的，换了微信号就是另一个「创建者」。

### 上传代码时提示域名未配置
→ 正式发布需要在小程序后台「开发设置 → 服务器域名」配置合法域名；或者把图片改为本地 `images/` 目录的方式（推荐）。

### 工具里报「appid 不合法」
→ `project.config.json` 里是占位值。按 [4.3](#43-拿到-appid) 修改 AppID，或重新导入项目时填入正确的 AppID。

## 一句话流程回顾

```
装开发者工具
  → 测试号导入项目（关闭域名校验）
  → 模拟器验收 8 项
  → 换新邮箱注册小程序 → 拿 AppID
  → 开通云开发 → 建 works 集合（仅创建者可读写）→ 填 CLOUD_ENV
  → 重新编译，验证云端生效
  → 真机预览验证拍照上传
  → 上传 → 设为体验版
```
