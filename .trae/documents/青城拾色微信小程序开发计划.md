# 青城拾色 · 茶染小助手 — 微信小程序开发计划

## 一、概述

为「青城茶染非遗研学」开发一个轻量级微信小程序（原生开发），服务于中小学生的课前预习、课中参考、课后留存。

**技术栈**

| 项目 | 方案 |
| --- | --- |
| 框架 | 微信小程序原生（WXML / WXSS / JS / JSON），不使用 uni-app、Taro |
| 小程序基础库 | 3.x（最新稳定版即可） |
| 后端 | 无自建服务器，使用微信云开发（云数据库 + 云存储） |
| 登录 | 无登录逻辑，依赖微信授权 + 云开发自动 `_openid` |
| 支付/核销/AR | 全部不做 |

**已确认的三项决策（来自你的选择）**

1. **云开发账号**：你目前没有正式 AppID，需要注册指导 → 计划中包含完整的「注册 + 开通云开发」操作指引；代码按云开发方案编写，同时提供**本地存储降级模式**，让你在注册完成前也能先跑起来看效果。
2. **图片/视频素材**：全部使用占位素材（在线占位图 + 公开占位视频），并集中在 `utils/assets.js` 一处配置，后期你替换成真实素材时只改这一个文件。
3. **作品分享图**：不引入 canvas 合成，直接用作品图作为分享卡片封面（`onShareAppMessage`），实现简单且稳定。

**页面结构（最终确定）**

底部 tabBar 共 4 个：首页 / 茶染教程 / 配方参考 / 我的作品。
「我的」**合并进「我的作品」页面顶部**（头像、昵称、作品数量、关于我们、联系传承人），不单独占一个 tab。

2. 登录后在「开发 → 开发管理 → 开发设置」拿到 **AppID**（形如 `wx1a2b3c4d5e6f7g8h`）。
3. 下载并安装 **微信开发者工具**（稳定版 Windows 版）。
4. 在开发者工具中用 AppID 新建/导入项目，目录选择 `g:\projects\qingchengcharan`。
5. 点击工具顶部「云开发」按钮 → 开通（选免费基础版）→ 创建环境（例如命名为 `qingcheng-prod`）→ 复制**环境 ID**。

**在你完成第 1–6 步之前**，程序会自动进入「本地存储模式」，UI 与操作流程完全一致，作品数据存在手机/工具本地缓存里；填好环境 ID 后自动切换为云开发模式，无需改任何业务代码。

## 五、数据模型

### 1. 配方（`utils/recipeData.js`，本地写死，不查数据库）

数组，共 **18 条 = 6 种原料 × 3 种布料** 的完整组合，保证任意选择都有结果：

| 字段 | 说明 |
| --- | --- |
| `ingredient` | 原料：绿茶 / 红茶 / 乌龙茶 / 银杏叶 / 楠木叶 / 其他落叶 |
| `fabric` | 布料：棉方巾 / 棉麻书签 / 其他 |
| `dosage` | 推荐染料用量（如「茶渣 80g」） |
| `waterRatio` | 水比（如「1:15」） |
| `mordant` | 媒染剂（如「明矾 5g/L」） |
| `temperature` | 浸染温度（如「80℃」） |
| `time` | 浸染时间（如「40 分钟」） |
| `tip` | 提示（注意事项） |

取值规则：同料不同布（布料越厚，用量/时间递增）；不同料的色相与茶类常识一致（绿茶→浅黄绿、红茶→红棕、银杏叶→黄、楠木叶→褐）。所有值在合理区间内成梯度，取值确定、可直接编码。

### 2. 作品（云数据库集合 `works`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 云开发**自动写入**，无需手动写（本地模式用 `local` 代替） |
| `name` | string | 作品名 |
| `imageFileID` | string | 云存储 fileID（本地模式存临时路径） |
| `ingredient` | string | 使用的原料 |
| `recipe` | string | 染料配方（手填） |
| `date` | string | 制作日期 `YYYY-MM-DD` |
| `note` | string | 心得（选填） |
| `createTime` | number | 创建时间戳 |

**云存储路径**：`works/{date}_{随机数}.jpg`；本地模式不涉及上传。

## 七、分阶段实施计划

### 阶段 0：工程骨架
**文件**：`app.json`、`app.js`、`app.wxss`、`sitemap.json`、`project.config.json`
- `app.json`：注册 7 个页面；`window` 设置导航栏标题「青城拾色」、背景色 `#F7F2E8`；`tabBar` 配置 4 项（**text-only，不带图标**，避免需要图标素材；`color` / `selectedColor` 用冬岩褐 / 春芽绿）。
- `app.js`：读取 `utils/config.js`，若配置了云环境 ID 则 `wx.cloud.init({ env, traceUser: true })`，否则跳过并置全局标志 `local`。
- `project.config.json`：`appid` 留占位符 `wxREPLACE_WITH_YOUR_APPID`，`compileType: miniprogram`。
- 验证：开发者工具能编译通过、4 个空白 tab 可切换。

### 阶段 1：基础设施层（数据 + 配置 + 素材）
**文件**：`utils/config.js`、`utils/assets.js`、`utils/util.js`、`utils/recipeData.js`、`utils/tutorialData.js`、`utils/store.js`
- `config.js`：导出 `CLOUD_ENV = ''`（你填环境 ID）、`USE_CLOUD`（由 `CLOUD_ENV` 是否为空推导）、`COLLECTION_WORKS = 'works'`。
- `assets.js`：集中导出 `HOME_BANNER`、`FOUR_COLORS[]`、`TUTORIAL_IMAGES[]`、`PLACEHOLDER_VIDEO`、`PLACEHOLDER_DISH` 等常量，全部指向在线占位资源；顶部写注释说明「替换真实素材只改此文件」。同时导出 `LOCAL_*` 备选路径（指向 `images/` 目录），替换后切换即可。
- `util.js`：`formatDate(date)`、`formatDateTime(ts)`。
- `store.js`（核心）：
  - `listWorks()` — 云模式：`db.collection('works').orderBy('createTime','desc').get()`；本地模式：`wx.getStorageSync('works')`。
  - `getWork(id)` — 按 `_id` 取值。
  - `addWork(data)` — 云模式：`db.collection('works').add({data})`，`createTime: Date.now()`；本地模式：插入数组并 `setStorageSync`。
  - `updateWork(id, data)` / `removeWork(id)`。
  - `uploadImage(localPath)` — 云模式：`wx.cloud.uploadFile({ cloudPath, filePath })` 返回 fileID；本地模式：直接返回本地临时路径。
  - 所有方法返回 `Promise`，两种模式签名一致 → 上层页面零感知。

### 阶段 2：首页 `pages/index`
- 顶部品牌区：标题「青城拾色 · 一叶一染」+ 副标题「茶染小助手」。
- Banner 图：`<image>` 引用 `HOME_BANNER`，占位图加载失败时降级为渐变底色块（`binderror` + 条件类名）。
- 青城四色展示：4 个色块卡片（春芽绿 / 夏烟青 / 秋落赭 / 冬岩褐），点击弹出该色的简短说明（`wx.showModal` 或页面内展开）。
- 三个大按钮：看茶染教程 → `switchTab` 到 tutorial；查染料配方 → `switchTab` 到 recipe；我的作品 → `switchTab` 到 works。
- 底部一句话：「用青城茶渣与落叶，染一方青城色」。

### 阶段 3：茶染教程 `pages/tutorial`
- 数据源：`utils/tutorialData.js`，5 个步骤（准备材料 / 煮染 / 媒染 / 固色 / 晾干与完成），每步含 `title`、`desc`（要点文字）、`points[]`（关键参数，如水温、时间、用量）、`image`、可选 `video`。
- 布局：竖向步骤时间轴，每步一张卡片（序号 + 标题 + 图 + 文字要点）。有视频的步骤在图片下方放 `<video>`（`src` 为 `PLACEHOLDER_VIDEO`）。
- 顶部提供「视频区」：一个主 `<video>` 组件，`poster` 用第一张占位图。
- 说明：教程内容全部写死在 `tutorialData.js`，后期改内容只改这一个文件。

### 阶段 4：配方参考 `pages/recipe`
- 选择器：`<picker mode="selector">` × 2 —— 原料（6 项）、布料（3 项），默认选中第一项。
- 「查看推荐配方」按钮 → 在 `recipeData.js` 中按 `ingredient + fabric` 精确匹配（数据保证 18 条全覆盖，无需兜底），渲染结果卡片：染料用量、水比、媒染剂、浸染温度、浸染时间、提示。
- 结果区未点击前显示占位提示文案；点击后平滑显示。支持「重置」。

### 阶段 5：我的作品 + 我的 `pages/works`
- 顶部「我的」区：头像（`<button open-type="chooseAvatar">`）、昵称（`<input type="nickname">`），保存到本地缓存 `userInfo`；右侧显示「作品 N 件」（调用 `listWorks` 取长度）。
- 功能区入口：关于我们、联系传承人 → 跳 `pages/about`。
- 作品列表：卡片网格/列表（作品图 + 作品名 + 日期 + 原料标签），点击进详情；右下角悬浮「+ 新增作品」按钮 → 跳 `work-edit`。
- 空状态：插画占位 + 引导文案「还没有作品，去记录第一件茶染作品吧」+ 按钮。
- 下拉刷新（`onPullDownRefresh`）重新拉取列表。

### 阶段 6：作品新增/编辑 `pages/work-edit`
- 图片选择：`wx.chooseMedia({ count:1, mediaType:['image'], sourceType:['album','camera'] })`，本地预览。
- 表单：作品名（必填）、使用的原料（选择器，复用原料枚举）、染料配方（多行手填）、制作日期（`<picker mode="date">`，默认今天）、心得（选填，多行）。
- 保存流程：校验必填 → `uploadImage` → `addWork`/`updateWork` → `wx.showToast` → `navigateBack` 并通知列表刷新。
- 编辑模式：通过 URL 参数 `id` 区分，回填数据；提供删除（`wx.showModal` 二次确认）。

### 阶段 7：作品详情 `pages/work-detail`
- 大图（支持 `wx.previewImage` 全屏查看）、作品名、原料、配方、日期、心得。
- 「分享给好友」：`onShareAppMessage` 返回 `{ title: 作品名, path: '/pages/work-detail?id=xx', imageUrl: 作品图 }`（云模式用 fileID 转换后的临时链接；本地模式用本地路径）。
- 「编辑」按钮 → 跳 `work-edit?id=xx`。

### 阶段 8：关于我们 `pages/about`
- 项目/非遗介绍文案（写死）、传承人/老师联系方式（手机号 `wx.makePhoneCall`、微信号可复制 `wx.setClipboardData`）、版本号。
- 联系方式集中放在 `utils/config.js` 的 `CONTACT` 对象，便于替换。

### 阶段 9：分享与联调收尾
- 全站关键页面配置 `onShareAppMessage`（首页、详情页）。
- 补齐各页 `navigationBarTitleText`。
- 逐页自测：4 个 tab 切换、配方 18 种组合抽测、新增作品→列表→详情→编辑→删除闭环、分享。
- 交付说明（我会在最终回复里给出，不额外建 md 文件）：如何填 AppID、如何填云环境 ID、如何切换真实素材、如何上传体验版。

## 八、假设与决策

| # | 决策 | 理由 |

| 1 | 「我的」合并进「我的作品」页顶部，不单独设 tab | 需求文档明确允许；4 tab 更简洁 |

| 5 | `recipes` 云集合本期不创建 | 配方由前端写死即可满足需求；如后期要后台可维护配方，再建集合，字段已在上文定义 |

| 8 | 占位素材使用在线链接 | 你已选择占位素材方案；需在开发者工具勾选「不校验合法域名」 |
| 9 | 不引入任何第三方 UI 库/组件库 | 需求强调「越简单越好」，原生组件足够 |
